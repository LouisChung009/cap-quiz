# 會考刷題 PWA

iPad / iPhone / Android / desktop 可安裝的會考刷題 PWA。

## GitHub Pages
1. 將本資料夾全部檔案放到 GitHub repository 根目錄。
2. Repository → Settings → Pages。
3. Build and deployment → Source 選 `Deploy from a branch`。
4. Branch 選 `main`、資料夾選 `/(root)` → Save。
5. 發布後網址通常為 `https://你的帳號.github.io/儲存庫名稱/`。

iPad 使用 Safari 開啟網址 → 分享 → 加入主畫面。
