# 社會科公民監督題型複核：2026-10-06

## 發現與修正

- 對照 SOC-0028、SOC-0031 題幹及能力點後，確認兩題原先都在測民意機關監督行政機關，雖情境略異，核心作答任務相近。
- SOC-0031 改為社區居民依公開資料程序取得公共工程資料、分享工程經費使用資訊，考查公民知情與公共監督；不再以議員查工程作同一層級題型。
- 保留「資料公開不等於取得採購決策權，也不取代司法判刑」的錯誤選項辨析與解題提醒；更新知識點和難度。
- 更新答案／考點一致性對照與社會科專項回歸測試。

## 驗證與限制

- `npm run validate:data --silent`、`npm run validate:quality --silent`、`npm run validate:answer-consistency --silent` 通過後再進行完整測試。
