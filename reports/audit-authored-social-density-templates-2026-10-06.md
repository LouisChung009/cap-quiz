# 社會科人口密度近重複題型複核：2026-10-06

## 發現與處置

- 以移除數字後的題幹文字相似度掃描，發現 SOC-0408／SOC-0585 及 SOC-0425／SOC-0464／SOC-0568 使用高度相似的比較或直接代公式題型；這是模板重複候選，不是單靠相似度推定錯題。
- SOC-0464 改為由人口與人口密度反求面積，測試公式變形與單位。
- SOC-0568 改為固定面積下求人口增加造成的密度增量，區分增量和更新後密度。
- SOC-0585 改為跨區比較人口密度差，辨別總人口較多不等於密度較高。
- 追加複核發現 SOC-0548／SOC-0935 情境相同：SOC-0935 改為政府總預算審議，驗證不同的憲政監督工具。
- SOC-0484／SOC-0586 都是扶養比直套公式：SOC-0586 改為比較兩地高齡人口占比，區分人口絕對數與年齡結構比例。
- 保留 SOC-0408 的雙區人口密度直接比較，讓同一考點涵蓋不同操作，不只是更換數字。
- 新增逐題回歸檢查，鎖定五題答案索引、計算式／判讀、教師提醒及三步解法；加入 `npm test`。

## 驗證

- `npm run validate:social-density-templates --silent` 通過五題逐題回歸檢查。
- `npm run validate:quality --silent` 通過五科題型模板、解析重複度、正解引用和答案位置分布檢查。
- `npm run validate:data --silent` 通過五科各 1,000 題與 1,098 題官方題庫，共 6,108 個唯一 ID。
- 全套 `npm test` 通過；數字替換題幹掃描仍為 0 組候選。
